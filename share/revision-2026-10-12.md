## 实际验证

执行环境 Node `v24.19.0`。这些是本轮新结果；文章中其他历史数字不算本轮重新验证。

- 全站静态：`python3 share/scripts/check-local-links.py` 检查 70 个 HTML；本地目标/页面锚点/重复 ID 零错误。内联 JavaScript 50 段通过语法解析。它们不证明 HTML 渲染或外网链接可达。
- Vue：144/144 连续来源块精确匹配；batch 三函数隔离运行 7 组错误边界；apiWatch 注释改动转译后 JS 与基线相同。窄范围声明审计 56 项中有 1 个既存匿名类型字段缺注释，与本次三个方法无关，无新增缺口。未运行 Vue 测试套件。
- React：65/65 连续来源块匹配；HTML Demo 与 Context A/A/B 对照通过，加载 197 个本地源码模块且无 npm React 回退。相关既有测试 AST/工具指令不变。详情见 harness 的 README/verification。
- Vite：源 Markdown 与生成器生成 HTML；二次生成一致性、来源片段和注释语义检查。真实 Runner 方法与作用域 walk 的隔离断言通过，不等于完整 Vite SSR 测试套件。
- micro-app：本地 EventCenter/CSSParser/动态脚本摘录的隔离断言通过；src 声明覆盖 1037 项、1011 注释、26 豁免，未分类/解析错误 0。审计器 constructor 分组输出有既存原型键问题，不引用该分组数字。未执行 catalog 浏览器组合用例。
- Yjs：`node examples/state-vector-diff.mjs` 与 `node examples/known-overlap-boundary.mjs` 均通过。后者是**缺陷特征通过**，不是正确合并保证；未穷举 Item/V2/provider。
- DOMPurify：`node examples/sanitize.cjs` 在锁定 jsdom 29.1.1 下通过。使用本仓已跟踪 CJS，未重新 build，未跑全部攻击 fixture、浏览器或类型测试。

## 浏览器验证限制

尝试云端 Chromium 启动，运行环境拒绝 socket；经正常授权重试仍失败。云端浏览器不支持 file 协议，正常 HTTP 本地预览也连接拒绝。因此本轮**没有完成真实浏览器宽/窄屏、复制、折叠和滚动视觉验收**。没有修改系统安全设置或把静态/模拟 DOM 检查写成浏览器通过；发布后仍建议在普通浏览器复核这些交互。

本仓顶层没有 `.github/workflows`。各库快照内嵌套的同名目录不是本仓可运行的 GitHub Actions 配置；远端提交状态另行核对，不以“没有任务”当作 CI 测试通过。
