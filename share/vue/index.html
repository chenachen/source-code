01 / The Three Guides

三份总结各自回答什么

三者不是平行孤岛。Compiler 提供页面描述，Reactivity 感知状态变化，Runtime 负责协调更新，并利用编译提示与节点复用减少 DOM 操作。

02 / End-to-end Chain

一条链串起三个系统

Compiler 主要发生在构建期；Reactivity 与 Runtime 主要发生在运行期。render 与组件更新副作用是两段流程的接缝。

Template / SFC开发者输入
→
render 函数Compiler 产物
→
依赖追踪render 读取状态
→
VNode + patchRuntime 更新页面
Compiler → Runtime 交付 render 函数、VNode 调用、PatchFlag、静态节点与 Block 信息，帮助 Runtime 少做比较。
Runtime → Reactivity 组件 render 作为响应式副作用执行；读取状态时形成依赖，更新调度器由 Runtime 提供。
Reactivity → Runtime 状态写入触发组件更新任务；Scheduler 合并任务，再由 Renderer 生成新 VNode 并 patch DOM。

UNDERSTAND FIRST

建立完整心智模型

  1. Runtime 零基础先修课先懂 VNode、patch、Diff 与调度各自解决什么。
  2. Reactivity 完整长文理解状态变化为何能准确唤醒对应组件。
  3. Runtime 架构至完整调用链把依赖触发接到页面更新。
  4. Compiler 总览与端到端串联补齐 render 函数与优化提示的来源。

TRACE THE SOURCE

沿一次更新精读源码

  1. Compiler integration从模板产物确认 render、VNode 与 PatchFlag。
  2. Runtime component / scheduler定位渲染副作用及任务入队。
  3. Reactivity flow / model追 track、trigger、Dep 与 Link。
  4. Runtime renderer / diff / DOM观察新 VNode 如何变成最少量宿主操作。

Vue 核心不是三个独立模块，而是三份协议：Compiler 描述可优化的页面，Reactivity 描述谁依赖谁，Runtime 决定何时、以什么最小代价让页面与状态重新一致。
