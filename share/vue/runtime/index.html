整套 Runtime 只围绕一个问题展开

状态变化后，Vue 要用尽可能少的工作，让浏览器页面与最新状态一致。

✎ 先算“应该长什么样” 组件读取最新数据，产生一份新的页面描述。 component + render
⇄ 再找“哪里不一样” 比较前后描述，保留能复用的部分，找出新增、删除和移动。 renderer + diff
✓ 最后修改真实页面 把必要操作翻译成浏览器 DOM、属性、事件和样式更新。 runtime-dom

调度系统决定这些工作什么时候做；Teleport、Suspense、KeepAlive 和 Transition 改变某些特殊时机；Hydration 则让 Vue 接管服务端已经生成的页面。
