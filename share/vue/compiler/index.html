01 / Mental Model

先建立一张总图

Vue Compiler 是“共享中间表示 + 平台注入 + 目标代码生成”的组合，而不是单一编译入口。

一句话模型：compiler-sfc 拆分并协调 .vue 文件；compiler-dom 与 compiler-ssr 选择目标平台；compiler-core 提供 Parse → Transform → Generate 骨架与共享 AST。

输入层

模板文本、SFC block、TypeScript 类型、CSS 与平台编译选项。

协议层

Template AST、JS AST、binding metadata、helper symbols、PatchFlags。

输出层

客户端 render、SSR ssrRender、setup 代码、CSS 与 source map。

02 / Packages

四个模块的责任边界

理解“谁不负责什么”比背诵 API 更重要。边界决定了代码放置位置，也解释了模块之间的复用方式。

compiler-core

平台无关模板编译内核

拥有 tokenizer、parser、AST、通用结构指令、表达式分析、静态优化与 JS codegen。它不知道某个标签是否是 HTML 原生元素，也不决定浏览器属性语义。

  • 输入：模板字符串或 RootNode
  • 输出：CodegenResult
  • 核心扩展点：ParserOptions、NodeTransform、DirectiveTransform

compiler-dom

客户端 DOM 平台适配

给 core 注入 HTML/SVG/MathML 解析规则，并覆盖 v-model、v-on 等 DOM 指令语义；还能把足够大的静态树序列化成 HTML 字符串。

  • 输入：DOM 模板
  • 输出：客户端 render 函数
  • 运行时协议：VNode、block、PatchFlags
进入模块详解
compiler-sfc

单文件组件编排与静态分析

先建立 SFCDescriptor，再分别编译 script/template/style。它承担 script setup 宏、跨文件类型解析、资产 URL、scoped CSS、HMR 依赖与映射合并。

  • 输入：完整 .vue 文件及构建选项
  • 输出：三个可由 bundler 组装的结果
  • 关键工具：Babel AST、MagicString、PostCSS
进入模块详解
compiler-ssr

服务端字符串输出目标

复用 DOM parser options 与 core 的作用域/结构能力，但不生成客户端 patch 优化。它通过两遍转换建立 _push() 输出与 hydration 边界。

  • 输入：模板字符串或 RootNode
  • 输出：ssrRender 函数
  • 关键约束：HTML 安全、attrs 透传、客户端 hydration 一致

03 / Principles

贯穿源码的七条设计原则

这些原则是阅读陌生函数时的判断坐标：代码分支复杂，但设计约束高度稳定。

  1. 1
    平台差异通过能力注入。core 只预留判断点，DOM/SSR 提供 namespace、标签、属性和指令规则。
  2. 2
    AST 是阶段协议。parser 描述模板语义，transform 追加执行意图，codegen 只负责可靠打印。
  3. 3
    转换顺序具有语义。结构指令先改树，作用域追踪先于标识符前缀，元素转换在退出阶段汇总 children。
  4. 4
    编译器与运行时共同优化。PatchFlags、block tree、helper symbols 都是跨包协议，不是局部实现细节。
  5. 5
    正确性优先于静态性。捕获局部变量、动态 key、运行时指令等场景会主动放弃提升或缓存。
  6. 6
    编辑态输入必须可恢复。parser 尽量保留 AST 与精确 location，让 IDE、HMR 和增量编译在残缺模板上继续工作。
  7. 7
    源码位置是一等产物。SFC、预处理器和模板 codegen 的多层 source map 最终必须回到用户编辑的 .vue 文件。
04 / Contracts

编译期与运行时的协议

Vue 的性能很大一部分来自“提前知道哪里会变”。编译结果不仅是 JavaScript，还携带更新策略。

信息如何逐层压缩

模板语义元素、指令、表达式
→
静态分析作用域与 ConstantTypes
→
编译提示PatchFlags / hoist / cache
→
运行时快路径只 patch 动态后代
协议 编译期负责 运行时得到的收益
Runtime Helpers 按符号登记实际使用的 helper 精确导入与稳定别名，避免携带无用能力
PatchFlags 标出 TEXT、CLASS、STYLE、PROPS 等动态维度 跳过完整 props/children 比较
Block Tree 记录动态后代并控制 block 边界 跳过稳定静态层级
Binding Metadata 区分 props、ref、maybe ref、let、literal const 绕过实例代理并选择正确读写方式
Scope ID 在正确 VNode/SSR 输出范围注入 data-v-* 属性 scoped CSS 与 slot 内容保持一致
