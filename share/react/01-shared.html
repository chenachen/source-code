shared：让六个包说同一种语言

packages/shared 不驱动一次 render，却决定元素如何被识别、跨包对象长什么样、 哪些实验路径进入构建，以及开发期错误怎样指向真正的调用现场。

54 个可解析源码文件 815 个结构声明 runtime + Flow contracts 包版本 0.0.0 / React 19.3.0

结论与边界

IDENTITY

全局 Symbol 是分派协议

JSX、reconciler、DevTools 和 renderer 依赖相同标记判断元素种类；它不是供业务计算的枚举值。

CONTRACT

Flow 类型是设计文档

ReactTypes.js 描述 element、context、portal、cache 与 transition 等跨包形状，构建后被擦除。

POLICY

flags 是构建策略，不是状态库

默认常量和平台 fork 让打包器选择路径并消除死代码；动态 variant 只在特定内部/测试构建保留双态。

不负责：shared 不持有 FiberRoot、不决定 Lane、不安排 host callback，也不执行 DOM mutation。 它提供类型标记、跨包约束和工具；部分诊断工具持有缓存、计数器或临时全局状态，运行上下文由调用方建立与恢复。

身份协议：为什么不是字符串常量

元素记录只是普通 JavaScript 对象。若仅凭字段猜测，用户对象可能被误判；若每份 bundle 创建局部 Symbol， 多副本 React 又不能互认。Symbol.for 根据字符串名称复用全局注册表中的身份，名称同时成为 renderer 与 DevTools 的跨包约定。ECMAScript 将这份注册表放在 agent 上：同一 agent 内的多个 realm 可以共享它。进程或 worker 之间传递元素则还需要独立的传输协议。

这里的“不变量”是每种语义一个唯一标记。仓库测试遍历全部导出，以 Symbol 值建立反向 Map； 一旦两个名称碰撞就立即抛错。具体类型能否由公开入口创建，还取决于对应构建的导出和 feature flag。

iterator 是同一协议层的兼容例子

getIteratorFn 只接受非 null 对象，再读取标准 Symbol.iterator 或早期 @@iterator。它返回“工厂函数”而非直接开始遍历，所以 children 消费者仍拥有调用时机、异常与迭代器清理。

私有桥：跨包共享同一份上下文

ReactSharedInternals

shared 从公开 react 包取出刻意命名为不可公开依赖的 internals 对象。hooks facade 读取当前 dispatcher、 transition/act 等代码共享当前上下文；对象由 React 客户端包创建，shared 只转交引用。

ReactInstanceMap

class component 的公开实例需要让 setState 等入口回到当前 Fiber。实现没有维护额外 Map， 而是在实例的 _reactInternals 字段上直接安装引用。class 实例构造完成后，reconciler 将它关联到当时的 work-in-progress Fiber；后续更新通过该 Fiber 及其 alternate 找到组件和根， 不会在每次 current/work-in-progress 切换时重写这个字段。

这条桥是私有实现细节。它说明当前 class 实例怎样回到 Fiber，不构成第三方代码可稳定读取 _reactInternals 的兼容承诺。

Feature Flags：一份语义，多组构建值

默认文件按“可落地/可删除、killswitch、持续实验、下一主版本”等维护阶段组织开关；fork 为 WWW、React Native、 test renderer 等目标给出不同常量。静态 export 让条件分支可被编译器折叠，这是 flags 保持简单常量而非运行时配置中心的主要收益。

OPEN SOURCE DEFAULT

明确稳定默认

例如浏览器 API、fragment refs、legacy context 等路径在默认文件中直接取布尔常量或 __EXPERIMENTAL__。

INTERNAL VARIANT

同一测试跑两态

www-dynamic 用 __VARIANT__ 模拟 gatekeeper，测试配置分别以 true/false 执行，暴露只在一态失败的分支。

fork 差异必须与消费点一起解释：enableObjectFiber 改变 Fiber 的创建表示， enableRetryLaneExpiration 改变饥饿恢复策略，enableViewTransition 打开跨 reconciler/DOM 的整条机制。 例如 retry lane 默认不设过期时间；开启 enableRetryLaneExpiration 后，root 调度扫描会为它计算 当前时间 + retryLaneExpirationMs 的期限，并在等待超时后标记为 expired。

诊断路径：先解释，再故意触发同一个错误

生产热路径常用 '' + value；Symbol、Temporal 或自定义 primitive conversion 可能在这里抛错。 开发构建先探测 coercion，打印“值被当作 key/attribute/CSS 等”的上下文，再执行同样表达式抛出， 失败值通常再次抛出相同的转换错误，栈中也保留调用 helper 的 React 入口。

成功值在开发环境多经历一次探测；失败值先被探测，再在日志后重放转换。若对象的转换方法有副作用， 这些调用都会执行该方法。生产构建移除 __DEV__ 检查，只保留消费方原有的字符串转换。

完整小用例：非法 key 从 JSX 到可定位异常

  1. 输入。JSX 的 key 是 Symbol 或在 primitive conversion 中抛错的对象。
  2. 开发探测。React JSX 工厂在真正拼接前调用 shared 的 checkKeyStringCoercion。
  3. 上下文日志。helper 输出“不支持的 key 类型”和类型名，说明失败发生在哪个用途。
  4. 原语义重放。testStringCoercion 执行 '' + value，异常沿 JSX 入口栈传播。
  5. 生产边界。__DEV__ 探测被移除，JSX 工厂直接执行 '' + value；Symbol key 仍会在这一步抛错。
